## Overview

GWToolbox++ is an external companion application for Guild Wars 1 that runs alongside the game, providing an enhanced minimap with custom agent icons, automated inventory management with ID/salvage rules, one-click build template switching, and a travel panel for instant district and outpost navigation. Used by tens of thousands of veteran players, it is the de-facto standard quality-of-life toolkit for endgame Guild Wars content.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **GWToolbox++** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Enhanced Minimap** | Custom markers, agent visibility toggles, and overlay information |
| **Inventory Manager** | Auto-ID, auto-salvage, and smart-stack rules for inventory management |
| **Build Templates** | Save and hot-swap skill bar builds with configurable keyboard shortcuts |
| **Instant Travel** | One-click outpost and district travel panel replacing manual navigation |
